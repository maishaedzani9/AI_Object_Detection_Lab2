# YOLOv8 Object Detection Lab

## 📌 Description
This project demonstrates object detection and tracking using YOLOv8 on an image, video, and webcam.

## ⚙️ Tools Used
- Python  
- YOLOv8 (Ultralytics)  
- OpenCV  

## ▶️ How to Run
1. Install dependencies:
   pip install ultralytics opencv-python

2. Run:
   python lab_1.py

3. Set source:
   - Image → "Asian market.jpg"
   - Video → "Cars Moving On Road Footage.mp4"
   - Webcam → 0

## 📊 Features
- Detect objects in images  
- Track objects in videos  
- Real-time webcam detection  

## ⚠️ Limitations
- Affected by lighting and motion  
- May miss objects in crowded scenes
